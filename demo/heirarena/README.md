# ⚖ HeirArena · 幽灵遗嘱

> **多智能体遗产辩论竞技场** — 把冰冷的法律计算，变成一场有人格、有冲突的 AI 家庭辩论秀。

## 🚀 一键运行

直接用浏览器打开 `index.html`，双击即可。**零依赖、零构建、离线可跑**。

## 📦 核心能力

| 能力 | 说明 |
|---|---|
| 🧮 确定性规则引擎 | 基于《民法典》§1127/§1130/§1062 硬编码核心继承逻辑，输出可追溯 |
| 🎭 6 个性格化 Agent | 中立执行官 + 贪婪长子 / 孝顺女儿 / 妻子 / 宠物猫 / AI 数字分身 |
| 🔥 3 种辩论模式 | 温和(3轮) / 火药味(5轮) / 狗血(6轮+反转) |
| ⚡ 实时可视化 | 打字机对话流 · 情绪值条 · 关系图连线动画（攻击红/结盟绿） |
| ⚖️ 裁决闭环 | 敲槌 → 饼图 + 分配树 + 规则依据 + 辩论结果合并解释 |

## 🏗️ 架构

```
输入层(遗产档案+剧情设定)
   ↓
规则+解析层(民法典规则引擎 → 法定参考份额)
   ↓
多 Agent 辩论层(提案→攻击→结盟→妥协→终审)
   ↓
输出层(饼图/关系树/辩论回放/解释)
```
